# Pyrosec

Fire resistance analysis of reinforced concrete sections (steel and FRP),
with a transient thermal solver written in Rust.

> Work in progress — milestone M0 (toolchain + 1D thermal solver).

## Predecessor

Pyrosec is the successor of **SCBEAM**, the author's 2021 undergraduate thesis
(Ingeniería Informática, CUJAE) on bending and shear checks of FRP-reinforced
concrete beams under fire.
